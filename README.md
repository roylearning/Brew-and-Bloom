# ☕ Brew & Bloom — Artisan Coffee & Hearth Bakery

A luxury, interactive web experience crafted for an artisan roastery and bakery. Built with modern vanilla JavaScript, Tailwind CSS, HTML5 Canvas, and Web Audio.

![Brew & Bloom Preview](images/hero-coffee.png)

## ✨ Features

- **☕ Ambient Cafe Audio**: Toggle relaxing, smooth lo-fi cafe vibes with balanced volume control.
- **✨ Creative Barista Mouse Interactions**:
  - Fullscreen canvas emitting floating warm coffee aroma vapor and tumbling roasted coffee beans following cursor movements.
  - Interactive Barista Crema Ring follower with contextual hover pills (`✨ Inspect Recipe`, `⏱️ Pour Ritual`, etc.).
  - Wind-reactive steam simulation rising from the hero espresso cup.
  - Latte art ripple wave on click.
- **📋 Interactive Menu & Customizer Modal**:
  - High-resolution photography for all 11 coffees, matcha, teas, and pastries.
  - Click any item to inspect tasting notes, origin, dietary info, caffeine content, and allergens.
  - In-modal customizer for alternative milks and sweetness levels.
- **🛍️ Live Order Bag (Cart Drawer)**: Real-time sliding drawer to add drinks, adjust quantities, and simulate pickup orders.
- **⏱️ Interactive Pour-Over Ritual Timer**: 3-stage live pour-over guide (Bloom, Continuous Spiral Pour, Drawdown) with audio and visual feedback.
- **🎨 Artisan Texture Patterns**: Subtle roast and woven linen patterns seamlessly blending with warm earthy tones.

## 🚀 Live Demo on GitHub Pages

Host this repository directly with GitHub Pages by enabling it in **Settings > Pages > Branch: `main` / `root`**.

## 🛠️ Local Development

Open `index.html` in any modern web browser or run:

```bash
# Windows PowerShell
Start-Process "index.html"
```
